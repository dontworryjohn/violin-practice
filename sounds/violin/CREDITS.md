# Violin sound credits

The violin notes in this folder (`55.mp3` = G3, the open G string, up to `84.mp3` = C6) are
recordings from the **Fluid R3 GM** SoundFont by Frank Wen, as pre-rendered to MP3 by the
[midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) project (`FluidR3_GM/violin-mp3`).

They are used under the
[Creative Commons Attribution 3.0 licence](https://creativecommons.org/licenses/by/3.0/).
The only change is the file names: each file is named after its MIDI note number.
