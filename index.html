How to type notes
  • String + finger: A0 = open A string, E1 = first finger on E.
  • Longer notes: add :2, :3 or :4 beats. Quick notes: :0.5.
  • Bar lines: put | between bars (or leave them out and they're added for you).
  • Rest: R (or R:2 for a 2-beat rest).
  • Low/high 2nd finger: chosen from the key; force it with E2L (G) or E2H (G♯).
